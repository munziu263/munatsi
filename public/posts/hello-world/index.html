I’ve had a website before. A few, actually. They always started ambitious and ended neglected.

This time I’m trying something different: start small, write consistently, let it grow.

I’m a software developer working on portfolio optimisation systems — Python, React, MySQL, and increasingly GPU programming. I’m also a father of four, which means my time is limited and my motivation to use it well is high.

This site will be a mix of:

  • Technical writing — things I’m learning, problems I’ve solved, tools I’m building
  • Reflections — on faith, discipline, fatherhood, career change
  • Notes — shorter pieces, links, things I found interesting

The goal isn’t to build an audience. It’s to build the habit of producing rather than just consuming. If something here is useful to you, that’s a bonus.

Let’s see where this goes.
