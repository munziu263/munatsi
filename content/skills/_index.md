Simon Willison maintains a collection of [tools](https://tools.simonwillison.net/) he's built — small, useful things that compound over time. He also writes about [hoarding things you know how to do](https://simonwillison.net/guides/agentic-engineering-patterns/hoard-things-you-know-how-to-do/) as an agentic engineering pattern: every time you figure something out, write it down in a reusable format so you and your tools never have to solve it from scratch again.

This page is my version of that. Reference cards for workflows, tools, and systems I use — documented so they're searchable, shareable, and ready to hand to an AI agent when I need them.
